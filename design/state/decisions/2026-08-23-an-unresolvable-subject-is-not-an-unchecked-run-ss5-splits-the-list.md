## Claim
One word was doing two jobs. *Unchecked* now means only a degraded run — environmental, unintended, fixable — and still forces exit 2, so `AGENTS.md` § *Verification* and I19/I20 are untouched. A second list, *unresolvable*, holds a check that completed against a subject a recorded decision placed out of reach; it is reported and counted every run and never changes run status. `CrossRepositoryUnresolvable` moves there and `RegisterAbsent` stays. SS5 rewords, SS6 counts four buckets so S4.6's sum still holds, SS9 keeps "never passed, never broken" verbatim, and new SS18 requires every completed run to name its unresolvable count — including one reporting `Valid` — so the report carries the fact the exit code no longer does. The unresolvable list is closed at one member and admission requires a recorded decision, not a hard check; widening it is a contract amendment.
